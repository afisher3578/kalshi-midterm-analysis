# Data

`data/processed` holds counts and metrics derived from three sources: Kalshi public market data, Media Cloud and
Wikimedia pageviews.

The MIT license in the repo root ([LICENSE](../LICENSE)) covers the code and documentation. It does not cover this
data. Source terms apply:

- Kalshi: the terms on redistributing derived aggregates have not been reviewed yet
  ([docs/sources/kalshi.md](../docs/sources/kalshi.md)).
- Media Cloud: the terms of use allow distributing aggregated counts and recommend attribution.
- Wikipedia pageviews: public data (CC0) under the Wikimedia Terms of Use.

A license for the data will be added once Kalshi's terms are confirmed. Status for every source:
[docs/licensing.md](../docs/licensing.md).

No story text, post text or user data is published.
